# Portfolio Novem Romadhofi Kika

Portfolio pribadi berbasis HTML, CSS, JavaScript, dan Bootstrap. Situs ini menampilkan profil, pendidikan, pengalaman organisasi, proyek akademik, serta kanal kontak.

## Menjalankan secara lokal

Buka `index.html` secara langsung atau jalankan static server dari direktori proyek.

## Deployment

Production tersedia di [portofolio-novem.vercel.app](https://portofolio-novem.vercel.app).
